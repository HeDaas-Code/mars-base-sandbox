## 一、终端界面视觉风格

### 1.1 整体视觉基调

**关键词：复古工业科幻（Retro-Industrial Sci-Fi）**

灵感来源于 1970-80 年代 NASA 任务控制台、《异形》(1979) 飞船计算机 UI、CRT 磷光屏终端，但并非纯粹怀旧——而是「100年后的工业级系统」，即：技术极度先进，但界面设计遵循**功能性至上、装饰极简**的太空工业原则。

核心视觉特征：
- **暗色主导**：屏幕 80% 以上面积为深黑/暗琥珀背景，仅文字与关键数据发光
- **磷光质感**：文字带有微弱的辉光（glow）效果，模拟 CRT 显像管特性
- **扫描线纹理**：全局叠加极淡的水平扫描线，营造老式显示器质感
- **信号噪点**：通信时叠加随机字符噪点，信号越弱噪点越多

### 1.2 配色方案

采用**琥珀色（Amber Phosphor）**为主色调——既呼应火星沙尘的橙红色调，又区别于常见的绿色终端，形成独特视觉记忆。

| 色彩角色 | 色值 | 用途 |
|---------|------|------|
| 主背景 | `#0a0805` | 终端底色，极深棕黑 |
| 次背景 | `#15100a` | 面板/分区底色 |
| 主文字 | `#ffb347` | 琥珀色，正文与默认输出 |
| 高亮文字 | `#ffd699` | 选中/聚焦/重要信息 |
| 次要文字 | `#8b6914` | 注释/次要信息 |
| 警告色 | `#ff4444` | 危险/资源告急 |
| 注意色 | `#ffaa00` | 警告/资源偏低 |
| 安全色 | `#4a9d4a` | 正常状态/成功操作 |
| 信号色 | `#66ccff` | 信号/通信相关（冷色点缀，与暖色主调形成对比） |
| 边框线 | `#3d2b1f` | 面板分割线/边框 |

**配色逻辑**：暖色（琥珀/红/橙）为主调传递火星环境与紧张感；唯一的冷色（信号蓝）用于通信相关元素，暗示「来自远方的连接」，形成视觉温度的反差。

### 1.3 字体风格

| 用途 | 推荐字体 | 说明 |
|------|---------|------|
| 终端正文 | JetBrains Mono / Fira Code | 等宽字体，支持连字，科技感强 |
| 标题/系统标识 | Share Tech Mono | 略带棱角的等宽字体，用于系统标题 |
| ASCII Art | Standard VGA / IBM PC 字符集 | 确保方块字符与线条对齐 |
| 中文显示 | 思源等宽 / Sarasa Mono SC | 中英文等宽对齐 |

**字号规范**：
- 正文：14px / 行高 1.6
- 标题：18-20px
- 状态栏：12px
- ASCII Art：12px（确保对齐）

**动态效果**：
- 光标：方块闪烁，频率 1Hz
- 文字输出：逐字打字机效果，模拟信号传输延迟
- 信号干扰时：字符随机抖动 / 偏移 1-2px

### 1.4 界面元素设计方向

- **边框**：使用 Unicode Box-Drawing 字符（`┌─┐│└┘├┤┬┴┼`）构建面板边框，而非实色矩形
- **图标**：以 ASCII Art 和 Unicode 符号为主（`▮ ◆ ▲ ● ○ ■ □`），不使用位图图标
- **进度条**：字符方块填充式 `▮▮▮▮▮▯▯▯▯▯`（50%）
- **分隔符**：`═══════` 或 `───────`
- **信号强度指示**：`[█▓▒░]` 四级渐变，从满格到空格
- **状态指示灯**：`●`（正常/绿）`●`（警告/橙）`●`（危险/红）`○`（离线）

## 二、界面信息架构

### 2.1 整体布局概念

采用**分屏面板布局**，模拟多窗格终端。核心原则：**中央为主，两侧为辅，顶部状态，底部输入**。

```
┌──────────────────────────────────────────────────────────────────────┐
│  [█▓▒░ 信号: 67%]  MSOL 14:23:07  警报: ●  节点: SAT-7↔RELAY-3      │  ← 顶部状态栏
├────────────┬───────────────────────────────────────┬─────────────────┤
│            │                                       │                 │
│  资源监控    │         主终端 / 通信区                │   小组成员状态    │
│ RESOURCES  │         MAIN TERMINAL                 │   CREW STATUS   │
│            │                                       │                 │
│ O₂  ██████  │  > [SAT-7] 信号已建立...              │  ◆ Cmdr. 陈睿   │
│     78% ⚠  │  > 正在解调载波...                     │    状态: 在线   │
│            │  > 连接到基地通信频道                   │    信号: █▓▒░   │
│ PWR █████   │  ────────────────────────────        │                 │
│     45% ⚠  │  [14:21] Dr. 林凯:                    │  ◆ Dr. 林凯     │
│            │  "这里的风暴比我们预计的要大...           │    状态: 活跃   │
│ H₂O ██████ │  我们已经第三天了，氧气循环系统          │    信号: █▓▒░   │
│     82%    │  出了问题。"                         │                 │
│            │                                       │  ◆ Eng. 赵明    │
│ TEMP  -23°C │  > [信号波动...]                     │    状态: 静默   │
│            │  > [数据包重组中... 2/3]               │    信号: ▒░░░   │
│ FOOD ████   │                                       │                 │
│     31% ⚠  │  [14:23] Dr. 林凯:                    │  ◆ Dr. 苏婉     │
│            │  "有人能收到吗？请回..."                │    状态: 未知   │
│ ─────────  │                                       │    信号: ░░░░   │
│ 预估续航:   │  > _                                 │                 │

├──────────────────────────────────────────────────────────────────────┤
│ > _                                                                   │  ← 输入区
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 各功能区详细设计

#### ① 顶部状态栏（Status Bar）

高度约 1-2 行，始终可见，显示全局关键状态：

| 元素 | 内容 | 说明 |
|------|------|------|
| 信号强度 | `[█▓▒░ 67%]` | 玩家与基地的连接质量，影响通信可用性 |
| 时间 | `MSOL 14:23:07` | 火星太阳日时间（Sol 火星日 + 时分秒） |
| 警报状态 | `●` / `●` / `●` | 三级警报指示灯 |
| 连接路径 | `SAT-7 ↔ RELAY-3` | 当前信号经行的卫星与中继节点 |

#### ② 左侧资源监控面板（Resource Panel）

宽度约 18-20 字符，纵向排列基地关键资源：

**显示内容**：
- **O₂ 氧气**：当前储量百分比 + 进度条 + 预估续航时间
- **PWR 电力**：电池/发电机状态 + 进度条
- **H₂O 水源**：净水储量 + 循环系统状态
- **TEMP 温度**：基地内外温度（火星昼夜温差大，影响生存策略）
- **FOOD 食物**：补给剩余量

**视觉细节**：
- 进度条用字符方块 `▮▮▮▮▮▯▯▯▯▯`
- 低于阈值时闪烁并变色（→ 橙色警告 / → 红色危险）
- 底部汇总「预估续航时间」，以倒计时形式呈现紧迫感

#### ③ 中央主终端区（Main Terminal）

占据最大面积，是核心交互区域，用于：
- **通信对话**：显示与基地成员的自然语言对话
- **系统消息**：信号建立、数据传输、系统事件
- **探索内容**：查看日志文件、解码数据、查看地图等
- **信号效果**：信号弱时消息出现乱码、缺字、重复

**消息格式规范**：
```
[14:21] Dr. 林凯:
"这里的风暴比我们预计的要大...
 我们已经第三天了，氧气循环系统
 出了问题。"

[14:22] [信号波动... 数据包重组 2/3]
[14:23] Dr. 林凯:
"有人能收到吗？请回..."
```

- NPC 消息带时间戳 + 发言者标识
- 信号干扰以 `[...]` 系统注释呈现
- 不同来源的消息可用细微颜色区分

#### ④ 右侧小组成员状态面板（Crew Status）

宽度约 18-20 字符，展示科研小组各成员实时状态：

每成员显示：
- **ASCII 头像/标识符**（见第四节 NPC 设计）
- **姓名与职务**
- **状态**：`在线` / `活跃` / `静默` / `离线` / `未知` / `紧急`
- **信号质量**：独立信号条 `█▓▒░`
- **简要情绪/健康指示**（可选）：`稳定` / `焦虑` / `受伤` 等

状态变化时有过渡动画（信号条渐变、状态文字闪烁）。

#### ⑤ 底部日志区（Log Strip）

高度 1-2 行的滚动条，显示系统级事件流：
```
LOG ▸ [14:20] 信号握手成功 ▸ [14:21] 接收消息 #0042 ▸ [14:22] 资源更新 ▸ ...
```
- 自动滚动，最新事件在右侧
- 可点击展开查看完整日志

#### ⑥ 输入区（Input Area）

底部独立一行，玩家自然语言输入：
```
> _
```
- `>` 提示符闪烁
- 支持上下键浏览输入历史
- 发送后消息出现在主终端区，带玩家标识 `[YOU]`

### 2.3 视图模式切换

终端支持 **Tab 切换** 不同主视图，左侧/右侧面板保持不变：

| 模式 | 快捷键 | 内容 |
|------|--------|------|
| 通信视图（默认） | Tab+1 | 与基地成员对话 |
| 探索视图 | Tab+2 | 浏览文件系统、解码数据、查看基地日志 |
| 地图视图 | Tab+3 | ASCII 火星基地平面图 / 周边地形 |
| 信号视图 | Tab+4 | 卫星轨道追踪、中继节点管理 |

## 三、视觉氛围与情绪设计

### 3.1 核心情绪三角

```
        孤独感 (Loneliness)
           /    \
          /      \
    科技感 ←——— 紧迫感
   (Tech)     (Urgency)
```

三种情绪需动态平衡：探索时偏科技感，通信中断时偏孤独感，资源告急时偏紧迫感。

### 3.2 孤独感设计

| 手法 | 实现 |
|------|------|
| 大面积黑暗 | 界面 80% 为暗背景，仅有少量文字发光 |
| 信息间隔 | NPC 回复有真实延迟（数秒~数十秒），期间屏幕近乎静止 |
| 静默状态 | 无信号时显示纯黑 + 闪烁光标 + 时间流逝计数 |
| 极简音画 | 无背景音乐，仅有微弱的电流底噪和偶发的信号杂音 |
| 距离感传达 | 对话中插入系统注释 `[传输延迟 4.2s]` `[信号来源: 225M km]` |

**关键场景**：玩家长时间无操作时，屏幕逐渐变暗，仅保留光标闪烁和顶部时间流逝——强化「一个人在远方」的孤独感。

### 3.3 紧迫感设计

| 手法 | 实现 |
|------|------|
| 资源倒计时 | 左侧面板持续显示 `O₂ 4天12h` 倒计时，数字实时跳动 |
| 警报闪烁 | 危险资源条目闪烁 + 顶部警报灯变红 |
| 信号衰减 | 信号强度实时波动，关键时刻突然下降引发焦虑 |
| 时间压力 | 某些事件有「窗口期」，超时则后果发生 |
| 视觉压迫 | 警报触发时屏幕边缘出现红色脉冲晕染 |

### 3.4 科技感设计

| 手法 | 实现 |
|------|------|
| 技术化措辞 | 系统消息使用技术术语：`载波解调` `数据包重组` `握手协议` |
| 数据可视化 | 信号波形 ASCII 图、卫星轨道参数、坐标数据 |
| 系统状态码 | 类似 Unix 风格的状态输出 `[OK]` `[WARN]` `[ERR]` `[SIG-LOSS]` |
| 命令行交互 | 保留命令输入能力，高级玩家可用命令操作（`scan` `ping` `decode` 等） |
| 字符化美学 | 所有视觉元素由字符构成，连「图标」也是 ASCII Art |

### 3.5 动态氛围系统

界面氛围会根据**游戏状态**动态变化：

| 游戏状态 | 氛围表现 |
|---------|---------|
| 正常通信 | 琥珀色主调，稳定辉光 |
| 信号微弱 | 噪点增多，文字偶发乱码，信号条闪烁 |
| 沙尘暴期间 | 整体色调偏红，扫描线加重，通信严重受阻 |
| 紧急警报 | 边框变红，警报区脉冲闪烁，文字偏暖橙 |
| 深夜模式 | 背景更暗，辉光减弱，模拟节能模式 |
| 信号完全中断 | 纯黑屏 + 光标 + 时间流逝 + 底噪波形 |

### 3.6 声音设计概念（辅助视觉）

虽然是文字游戏，但建议加入极简音效以增强沉浸：

- **底噪**：持续的微弱电流嗡鸣
- **打字音**：文字逐字输出时的键盘敲击声
- **信号杂音**：通信时的白噪声/静电声
- **警报音**：低频蜂鸣（仅在危急时触发）
- **无信号**：完全静默（此时静默本身就是最强的声音）

## 四、NPC 形象概念

### 4.1 呈现方式总则

**核心原则：不使用写实头像，所有 NPC 形象由字符构成。**

理由：
1. 与终端整体风格统一
2. 字符化的形象天然带有「远距离通信」的隔阂感
3. 激发玩家想象力，比写实图像更能营造叙事氛围

**三种呈现层次**：

| 层次 | 形式 | 用途 |
|------|------|------|
| 标识符 | 1-3 字符的符号 + 颜色 | 状态面板中的紧凑显示 |
| ASCII 头像 | 8-12 行的 ASCII Art 肖像 | 对话时的角色立绘 |
| 文字描述 | 风格化的角色描述文本 | 首次接触/重要剧情节点 |

### 4.3 NPC 状态系统

每个 NPC 在状态面板中的显示：

```
◆ Cmdr. 陈睿
  状态: ● 在线
  信号: █▓▒░ 58%
  情绪: 稳定
```

状态可包括：
- **在线 / 活跃**：正常可通信
- **静默**：有连接但无响应（人在忙/受伤/不愿回应）
- **离线**：无连接
- **未知**：信号无法确认状态（最令人不安的状态）
- **紧急**：发送了求救信号

信号质量影响 NPC 消息的完整度——信号差时消息会出现乱码：

```
[14:25] Dr. 林凯:
```

## 七、设计原则总结

| 原则 | 说明 |
|------|------|
| **字符至上** | 所有视觉元素由字符构成，不使用位图，确保终端一致性 |
| **暗色主导** | 界面以黑暗为底，仅关键信息发光，强化孤独与聚焦 |
| **暖冷分明** | 主调暖色（火星/人），点缀冷色（信号/远方） |
| **动态氛围** | 界面氛围随游戏状态变化，非静态 |
| **留白即叙事** | 无信号时的黑暗和静默本身就是叙事手段 |
| **克制装饰** | 每一个视觉元素都应服务于功能或情绪，拒绝纯装饰 |
