## 四、根因分析

1. **角色混淆**：马库斯和索菲亚的数据疑似互换了部分字段（马库斯被写成地质学家，索菲亚被写成医疗官），可能参考了早期草稿而非 v1.1 终版。
2. **符号占位符未替换**：艾莎的 symbol 字段为 ` broadcasting `（英文单词），疑似开发过程中临时占位忘记替换。
3. **性格/说话风格使用了概括改写而非原文**：多处用"温和/冷静"等通用词替代了 v1.1 中更具辨识度的性格描述（如"黑色幽默""预言式感知力""不信任AI决策"）。
4. **年龄与 v1.1 全部不符（马库斯除外）**：可能参考了不同版本的角色设定。

## 五、建议

1. 以 v1.1 §1.4 NPC 设定表为唯一数据源，重新生成 npc-config.js。
2. symbol 字段严格对齐《前端视觉规范_CSS参数表》§1.2 和《视觉CSS规范》§1.2。
3. 修复后建议千机做一轮回归验证，确保 SignalRenderer 和 CrewPanel 渲染正确。
