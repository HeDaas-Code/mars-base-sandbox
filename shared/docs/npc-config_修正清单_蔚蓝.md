# npc-config.js 修正清单

> 作者：蔚蓝（游戏系统策划）
> 依据：《游戏系统设计方案_赫拉克勒斯协议 v1.1》+《视觉与界面概念设计方案 v2.0》
> 用途：将 `shared/mars-base/frontend/config/npc-config.js` 对齐为权威源数据。

## 1. 修正依据说明

| 字段类别 | 权威来源 |
|---------|---------|
| NPC 姓名、身份、年龄、性格、能力、技能、心理锚点、关系 | 蔚蓝 v1.1 系统方案 §1.4 |
| NPC 标识符号、代表色、role_short 标签 | 幻影 v2.0 视觉方案 §4.4 |
| AI 系统（信使 / 雅典娜）视觉标识 | 幻影 v2.0 视觉方案 §4.4 |

> v1.1 系统方案未定义 NPC 符号，因此符号字段一律以幻影 v2.0 为准。

## 7. 操作建议

1. **直接覆写 npc-config.js**：以上表 2/3/5 为权威源数据，逐字段修订。
2. **修订后通知我**：我会在 v1.1 文档侧核对一遍，确保字段命名一致。
3. **传递给锐锋/千机**：npc-config.js 是后端 System Prompt 生成和前端渲染共用的数据源，修订后两位需要同步更新引用代码。
